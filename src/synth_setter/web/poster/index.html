Abstract

Sound matching asks how synthesizer controls can reproduce the audible shape of a reference. The current browser demo uses a conditional flow-matching model: reference audio plus either extracted or authored music-sketch controls generate 92 encoded coordinates, which decode to 89 Surge XT synthesizer parameters. Surge XT then renders the generated patch locally in the browser.

Loading is opt-in because the model and engine require about 200 MB of downloads. A short, low-step run checks integration rather than sound-matching quality.

The model has not been downloaded.

Open standalone evaluator

Inference runs on the CPU via WebAssembly. The model generates synth parameters; Surge XT renders the audio. The current model does not preserve or stay near the parameters of an existing preset.

Method

Reference representation

The model consumes stereo mel features from the reference audio and 386 music controls on 32 frames. Controls can be extracted from separate sketch audio or authored as a pitch activation contour with loudness, spectral-centroid, onset, and end values.

Flow inference

Classifier-free guidance can use content and sketch together or independently. A seeded RK4 sampler predicts the encoded parameter coordinates, which are decoded into a Surge XT patch and rendered by the browser engine.

Current evaluation

The page reports integration diagnostics including normalized mel MAE, waveform RMSE, RMS levels, and peak amplitude. These measurements check a run's wiring and output; they are not a published perceptual evaluation or a preset-preservation result.

Code

The open-source synth-setter repository contains the data pipeline, training and evaluation code, ONNX export, and browser evaluator used by this page.

Limitations

  • The browser engine is an experimental Surge 1.4 port; training used SurgePy 1.3.4.
  • The demo is specific to Surge XT and four-second, 44.1 kHz stereo inputs.
  • Low-step smoke runs verify integration, not model quality or perceptual similarity.
  • The current model does not promise that a generated patch stays near an existing preset.
  • FXP upload and FXP export are not available in the current demo; current downloads are rendered WAV audio and a JSON evaluation record. FXP upload and export are planned to be added shortly.
