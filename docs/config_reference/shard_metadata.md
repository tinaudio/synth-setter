# Shard Metadata

`ShardMetadata` is the strict pydantic payload written into each Lance
shard's schema metadata. It mirrors the `RenderConfig` fields and serves
as a trust boundary for JSON read off R2. The autogenerated field list
below is the source of truth — refer to it for the complete schema. Every
shard, including pyFDN with its zero-valued MIDI stub, carries a
`render_contract_digest`: the SHA-256 of canonical JSON for its `RenderConfig`,
excluding shard placement and local-retention controls that cannot affect audio.
